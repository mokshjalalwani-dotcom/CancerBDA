# CancerBDA — Cancer Big Data Analytics

> Big Data Analytics coursework project — cancer dataset analysis using distributed computing and ML pipelines.

## Overview

Applies Big Data techniques to large-scale cancer clinical datasets. Implements distributed data processing, feature engineering, and predictive modeling using PySpark.

## Tech Stack

- **Language:** Python
- **Big Data:** PySpark
- **ML:** Scikit-learn, MLlib
- **Environment:** Jupyter Notebook

## Key Concepts

- Distributed data processing with PySpark RDDs and DataFrames
- ML pipelines for classification and survivability prediction
- Feature selection and dimensionality reduction at scale

## Run

`ash
pip install pyspark
jupyter notebook
